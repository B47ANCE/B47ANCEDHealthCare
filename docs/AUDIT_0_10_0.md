## Evidence and authority model

[VERIFIED — installed source] Steam app 108600 manifest build **25485521**. Exact engine patch version **UNKNOWN**; `versionMin=42.20.3` is a requirement, not proof of the installed patch. Portable Lua/class fingerprints and bounded observations are in `API_EVIDENCE_0_10_0.json`. No JVM/game/server was launched and no game files were modified. Native bytecode was inspected only to trace existing engine control flow; no custom Java/runtime dependency was added.

Vanilla `ISBaseTimedAction:create` constructs `LuaTimedActionNew`. Its inspected constructor checks the action metatable's `complete` member. Shared bandaging places mutation in `complete`; the client medical-check action performs presentation locally. `NetTimedAction.perform` calls `complete` on its authority path; `getDuration` uses adjusted Lua units converted by 20 ms. This supports reusing native timing instead of inventing a parallel timer protocol. It does not prove every custom userdata argument reconstructs successfully in a real server.

Client recovery actions queue intent through the native action system. The server's shared completion validates actor, exact owned saw/container/condition, loaded corpse, reach, clothing, knowledge, anatomy and provenance before `medWorks.sever`. MORTIS owns canonical anatomy and its replication; Health Care owns inventory output/rollback/quarantine and the medical ledger. Clients never create recovery items. Native inventory replication, reconnect/restart/late join and animation/action cancellation are not certified by source inspection.

Read-only examination uses local or native remote BodyDamage observations and the bounded completed-observation cache. It does not mutate canonical treatment/anatomy state or query Knox infection. Native health-panel proximity/subscription is not an invasive-procedure consent handshake; no invasive clinical provider is authorized by that UI alone.

Meaningful gameplay recovery settings remain server interpreted. Examination enable/time are local presentation behavior using world sandbox values. Technical limits, transport internals and validation guards remain internal. Save schema remains 1, with the original `medWorks` API/item/network/storage identities. Existing malformed saves are rejected rather than repaired silently. Historical packages and earlier validation records retain their actual versions.
