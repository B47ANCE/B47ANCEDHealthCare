[h1]B47ANCE'd Health Care[/h1]

Medical examination, treatment, surgery, trauma procedures, and recovery infrastructure for theWorks ecosystem.

B47ANCE'd Health Care owns authoritative medical actions while consuming shared entity and anatomy capabilities where a procedure requires them.

[b]Mod Version: 0.12.1[/b]

[b]Development Status[/b]

The examination and procedure framework is implemented and actively tested; deeper treatments, presentation, and multiplayer validation remain in development.

[h2]Current Features[/h2]
[list]
[*]Bounded read-only examination-provider API
[*]Localized View last examination report for a completed observation, with safe provider formatting and a scrolling local-player window

[*]Local wound infection kept distinct from Knox infection

[h2]Migration from medWorks[/h2]
Select B47ANCEDHealthCare instead of medWorks in mod lists. Existing Workshop item 3788592396 is retained. Dependent mods, including Nightfall, must update their required Mod ID before using this build. Lua API, item types, saved state and sandbox keys remain medWorks for compatibility. Back up existing saves; validate migration on a disposable copy. Rendered limb removal and a complete clinical treatment loop remain unfinished.

[h2]Configuration[/h2]
Server sandbox settings control examination and recovery availability, duration and recovery knowledge requirements. The displayed page is B47ANCE'd Health Care; stored medWorks setting keys are preserved.
